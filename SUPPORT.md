## What support looks like

LLMScribe is maintained part-time by one person. Expect a first response within about
**7 days**.

There is no SLA, no paid support tier, and no guarantee that a reported issue will be
fixed. Issues that fit [VISION.md](VISION.md) are far more likely to be acted on.

## Before opening an issue

- Update first: `pip install -U llmscribe`, and check the problem still happens.
- Search the existing issues — the answer may already be there.
- Reduce the problem to a small example. **Remove private code, paths and secrets**; the
  shape of the input is what matters, not the contents.
- Include the output of `llmscribe version`, your Python version, and which interface
  you used.
